# 设置页面由工具栏页面撑满窗口

设置页面放在主窗口里。它开着时，工具栏那个本地页面撑满窗口，设置内容画在工具栏下面；粉笔页面保持原来的大小，挪到窗口下边缘之外，所以它不重新排版、不刷新，计时照常走，回来时和离开时一样。键盘焦点跟着走：开着时在工具栏页面（Esc 和快捷键由它收），关掉时还给粉笔页面。不新增第三个页面，也不开独立窗口。

Linux 上窗口里的页面不能挪到窗口之外，所以改成隐藏粉笔页面的控件、让工具栏页面吃掉全部空间。

## 没选的做法

- **独立的设置窗口**：负责人看过同类软件的对照后，选了主窗口里的页面。
- **第三个页面盖在粉笔页面上**：项目钉死的这个版本的 Tauri 不能调整页面的叠放顺序，Linux 上页面也不能互相盖住。
- **把粉笔页面的高度设成 0**：页面会重新排版，回来时不再是离开时的样子。
