# 包装层自己联网检查更新

用户在软件里看不到有没有新版，所以包装层每次启动向本仓库的 GitHub 发布页发一个只读请求，读出最新版本号；用户也可以在设置页面里手动再查一次。包装层只读这一个版本号：不下载、不安装，下载由用户在系统浏览器里打开发布页完成。这是包装层唯一一处自己发起的联网请求，它不碰粉笔网站，也不带任何用户信息。

## 没选的做法

- **Tauri 自带的自动更新**：它要软件经手安装包，还要给每个发布签名、维护更新清单。这里只需要让用户知道有新版，用不着这些。
- **不检查，只在 README 里写下载地址**：用户不会回头看 README，装了旧版的人不知道有新版。
