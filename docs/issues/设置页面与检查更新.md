# 设置页面：显示版本号与检查更新

状态：进行中（齿轮和启动时检查更新已做；设置页面的版式已定；代码第 1 块未开工）

## 要解决什么

用户在软件里看不到自己装的是哪一版，也不知道有没有新版、去哪里下载。Windows 没有菜单栏，问题最明显。

做成后：用户点工具栏上的齿轮，进入设置页面，能看到当前版本号；有新版时齿轮带红点，设置页面里能去发布页下载。

总的口味：克制，尽量不影响正在做题的人。

## 已定的决定

| 事项 | 决定 |
| --- | --- |
| 入口 | 工具栏只加一个齿轮按钮；版本号不放窗口标题栏 |
| 设置界面 | 点齿轮，主窗口里粉笔页面那一块换成设置页面；工具栏留着；粉笔页面在后面保持原样，不刷新、不跳转 |
| 设置项 | 第一版只有「版本与更新」一组；以后有新设置再加组 |
| 版式 | 浅灰底上一张白卡片；规范见 `DESIGN.md` |
| 版本号 | 设置页面「版本与更新」一组里，取自 `tauri.conf.json` |
| 自动检查 | 每次启动查一次，运行中不再查 |
| 版本来源 | 本仓库的 GitHub 发布页（最新发布） |
| 新版提醒 | 只有齿轮上的红点，不出文字、不弹窗；用户打开设置页面后红点消失，出了更新的版本再亮 |
| 工具栏收起时 | 不显示齿轮；展开把手不带红点 |
| 下载 | 用系统浏览器打开 GitHub 发布页，软件不经手安装包 |
| 本地记录 | 只存一个「已看过的版本号」，和工具栏展开/收起状态同一目录 |

细节：

- 设置页面第一版只有「版本与更新」一组，是一张卡片。卡片第一行：应用图标（用 `src-tauri/icons/` 里现有的）、应用名「粉笔刷题」、「当前版本 v<版本>」，右边是「检查更新」按钮。
- 手动检查：按钮文字变成「正在检查更新…」，前面有一个转圈的圆环。查完卡片多出第二行：颜色圆点加一句「已是最新版本」（绿）/「发现新版本 v<版本>」（蓝）/「检查更新失败，请稍后再试」（红）；有新版时这一行右边是「下载新版 v<版本>」按钮。工具栏不出字。自动检查失败不出提示。
- 回到粉笔页面：页面左上的返回箭头（紧挨「设置」标题，悬停显示「返回」）、再点齿轮、按 Esc。
- 设置页面开着时，工具栏的返回、前进、回题库、刷新、收起都变灰，它们的快捷键不起作用。
- 「下载新版」用系统浏览器打开发布页；网址写死在 Rust 里，界面只发动作、不传网址。
- 齿轮在三个平台都显示，位置在工具栏右侧、收起按钮的左边。齿轮没有快捷键，悬停提示是「设置」。
- 做法：设置页面开着时，工具栏那个本地页面撑满窗口，设置内容画在工具栏下面，粉笔页面藏起来；不新增第三个页面。第 1 块先试通，试不通就停下来找负责人。
- 最新版本号的读法：请求发布页网址，从跳转地址读版本号。请求用 `ureq` 在后台线程发，带超时。
