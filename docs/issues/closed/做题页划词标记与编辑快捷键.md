# 做题页：划词标记与编辑快捷键

状态：已完成（划词标记第一版已做；按 E 打开编辑、改键不做，留给下一版）

来源：GitHub 议题 #11（用户反馈）；同一位用户的 fork `zhang765399515/fenbi-desktop`。

## 用户想要什么

1. 用按键打开当前题的编辑功能：鼠标移到一道题上，按 E 打开编辑，再按 E 退出。按键希望能在设置里自定义。
2. 划词标记：选中文字后自动填充背景色，用来分段和标重点；不限于现在的划线。不开编辑时也能划词更好。标记可以保留，交卷后清除也可以。
3. 标记可以换颜色。
4. 能删掉单独一处标记，也能一次清掉一道题的全部标记。
5. 标记和删除的按键能在设置页面里改。

第 1、2 条来自 #11 的原文。第 3 到 5 条 #11 没写，是从用户 fork 里做出来的功能看出来的。

## 决定（2026-11-28，负责人拍板）

- **边界放宽一次**：只允许在做题页注入划词标记脚本，用 CSS Custom Highlight API 叠底色；不改站点页面结构、不读题目数据、不调站点接口、不落盘。记在 `CLAUDE.md`「包装层的边界」和 `docs/adr/0004-做题页划词标记放宽注入边界.md`。
- **按 E 打开站点的编辑**：第一版不做（要包装层去点站点的按钮，属于驱动站点业务）。
- **触发方式**：选中文字后按 H 才上色，不是选中即上色。
- **标记留多久**：只在当前页面，刷新、离开就没了。
- **颜色、删除、改键**：3 种固定颜色；鼠标停在一处标记上按删除键删这一处；一个键清当前题全部标记。改键留到下一版。

## 做法

`src-tauri/highlight.js`，经 `lib.rs` 和 `init.js` 一起注入。按键、颜色、「当前题」怎么界定、哪些情况不拦键，见 `CONTRIBUTING.md`「做题页的划词标记」；做题页的结构见「已验证的站点事实」。

替用户补的细节：

- 标完取消选区：浏览器把选中态画在高亮上面，不取消看不见颜色。所以换色是「鼠标停在那一处上按 H」（重新选中同一段再按 H 也行）。
- 清当前题用 `Shift+Delete`（mac 上 `Shift+` 删除键）：和删一处是同一个键，加 Shift 表示范围更大。「当前题」是鼠标所在的 `app-ti`；页面上找不到 `app-ti` 时清掉本页全部标记。
- 颜色：浅橙 `#ffd8a8`、浅绿 `#c3f0c8`、浅粉 `#ffc9de`，避开站点的蓝色选中态和站点划线库的黄色。
- 做题页只认真实页面上核实过的 `spa.fenbi.com` 练习（`/ti/exam/exercise/<id>`）和背题（`/ti/memorize/<id>`），路径必须正好带一个 id。
- 一处标记只属于一道题：从一道题拖选到另一道题按 H 不标，选区留着。
- 鼠标移到工具栏或窗口失焦后，删除键不再删标记。
