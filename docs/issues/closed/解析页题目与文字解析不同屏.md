# 解析页：1080p 下题目和文字解析不在同一屏

状态：已完成（v0.1.4 隐藏了未开会员时的视频块；「文字解析放到题目右侧」不做）

来源：GitHub 议题 #10（用户反馈）。

## 要解决什么

1080p 屏幕上看解析页，带解析视频的题，文字解析被挤到一屏之外，用户要来回滚动对照选项和解析。用户建议：窗口够宽时把文字解析放到题目右侧，解析视频放到文字解析下面。

## 已查实的事实

2026-11-26 在真实解析页（`spa.fenbi.com/ti/exam/solution/...`，登录态，非会员账号）上量的，题干顶到页头下方时：

| 情况 | 一屏可用高度 | 文字解析从哪里开始 | 结果 |
| --- | --- | --- | --- |
| 视口 1920×965（1080p、100% 缩放），有解析视频 | 约 900 | 约 810 | 只露出解析标题和第一行 |
| 视口 1536×750（1080p、125% 缩放），有解析视频 | 约 690 | 约 810 | 完全看不到 |
| 视口 1920×965，没有解析视频 | 约 900 | 约 540 | 题目和整段解析同屏 |

- 一道题从上到下：题目选项（`app-question-choice`）→ 答案统计条（`app-solution-overall`）→ 解析视频 → 文字解析 → 考点 → 来源 → 笔记。后五段都是 `app-result-common` 里的 `section.result-common-section`。
- 往下挤文字解析的是「解析视频」整段，约 380 高。只有部分题带解析视频（实测一份 15 题的练习里有 7 道）。
- 会员广告（`.member-container`，270×315）排在视频（`.video-container`，540×315）的右边，同一行、一样高。只隐藏广告，文字解析的位置不变。
- 页面两侧各有约 130 宽的空白，题目卡片内部右半边基本是空的。
- 两个视口尺寸是按 Windows 任务栏 48、标题栏约 31、工具栏 36 推算的，没有在 1080p 实机上量；模拟用的是 macOS 的浏览器。

## 已做的

v0.1.4 起，未开会员时解析页的视频块整段隐藏（`init.js` 的 `UPSELL_BLOCK_SELECTORS`，提交 `1fdd9b0`），文字解析顶到视频块原来的位置。按上表「没有解析视频」那一行，1080p、100% 缩放下题目和整段解析同屏。会员账号照常显示视频，对会员这个问题还在。

没验证的：隐藏视频块之后，没有在 1080p 的 Windows 实机上看过；125% 缩放下没有重新量过。
