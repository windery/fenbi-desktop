# 解析页：题目与文字解析左右分栏

状态：已完成（纯 CSS，窗口宽度 ≥ 1400px 分栏）

来源：GitHub 议题 #10（用户反馈）；同一位用户的 fork `zhang765399515/fenbi-desktop`。

## 要解决什么

看解析页时，用户要对照题目选项和文字解析。窗口够宽时，题目在左、文字解析在右，不用上下滚动对照。

v0.1.4 隐藏了未开会员时的视频块，非会员账号在 1080p、100% 缩放下题目和文字解析已经同屏。会员账号有解析视频时，文字解析仍然被挤到一屏之外。

## 决定（2026-11-28，负责人拍板）

- 纯 CSS 实现，不碰「只注入 CSS」的边界。
- 窗口宽度 ≥ 1400px 才分栏；窄了保持上下排。
- 解析视频放右栏最上面，下面接文字解析。
- 「考点」「题源」「笔记」都留，放在右栏文字解析下面。
- 粉笔改版、选择器对不上时，退回现在的上下排。

## 做法

`init.js` 的 `SPLIT_SOLUTION_CSS`：`@media (min-width: 1400px)` 里，把每道题的 `.solution-choice-container` 改成两栏等宽的 grid。左栏是题目选项和答案统计条，右栏是 `app-result-common`（站点原来的顺序就是解析视频 → 解析 → 考点 → 来源 → 笔记）。容器选择器用 `:has()` 要求三块都在才命中，单独成条。细节见 `CONTRIBUTING.md`「UI 裁剪」的「解析页左右分栏」，量过的版面见「已验证的站点事实」。

## 没做的

- 没有会员账号，没有看过真正的会员页面。会员时的视频块是在非会员页面上「不藏视频块、只藏会员遮罩」模拟出来量的。
- 只看过单选题的解析页；材料题、申论这类结构不同的题，选择器不命中，保持上下排。
- 没在 App 的系统 WebView 和 Windows 实机里看过；量尺寸用的是 ego-browser（Chromium 内核）。
- 左栏不跟着滚动（sticky）：没有要求，没做。
