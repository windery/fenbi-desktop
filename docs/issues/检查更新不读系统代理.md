# 检查更新不读系统代理

状态：needs-triage（等负责人决定做不做、怎么做）

## 要解决什么

检查更新的请求只认环境变量里的代理设置，不读 macOS 和 Windows 的系统代理。靠系统代理才能打开 GitHub 的用户，浏览器能打开发布页，软件却连不上。

对这部分用户的后果：

- 启动时的自动检查失败，齿轮上不出现红点。
- 手动点「检查更新」，看到「检查更新失败，请稍后再试」。
- 其它功能不受影响，用户可以自己去发布页下载新版。

## 已知的

- 请求是 `src-tauri/src/update.rs` 用 `ureq` 发的。
- 「只认环境变量」这个结论来自读 `ureq` 的源码，**没有在真机上试过**。动手前先实测确认。
- `ureq` 有 `win-system-proxy` 开关，可以让它读 Windows 的系统代理。macOS 没有对应的开关。
