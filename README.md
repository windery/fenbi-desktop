# 粉笔刷题

粉笔题库的桌面版。打开就进题库，不用每次在浏览器里翻菜单。

macOS / Windows / Linux 都能用。

## 它解决什么

在浏览器里刷题的麻烦：

- 题库入口藏得深，每次都要点好几层
- 标签页一多就找不到了
- 登录完还停在原地

这个 app 就干一件事：**打开它，你就在题库里。**

登录一次之后通常不用再登。会话本身由粉笔网站控制，app 只在本地记一条观察记录；
页面加载后它会读粉笔的登录 cookie 与记录核对。本地能读到凭证，不等于服务端仍然认。

## 安装

### macOS

下载 `.dmg`，把「粉笔刷题」拖进「应用程序」。

未签名，首次打开会被 Gatekeeper 拦。两个办法：

- 在「应用程序」里**右键 →「打开」**，然后确认
- 或者执行一次：`xattr -dr com.apple.quarantine /Applications/粉笔刷题.app`

### Windows

下载 `.exe`（安装包），双击安装。

未签名，SmartScreen 会提示。点**「更多信息」→「仍要运行」**。

首次运行会自动准备 WebView2 运行时。

### Linux

- `.AppImage`：加执行权限后直接运行
  ```bash
  chmod +x fenbi-desktop_*.AppImage && ./fenbi-desktop_*.AppImage
  ```
- `.deb`：`sudo dpkg -i fenbi-desktop_*.deb`
- `.rpm`：`sudo rpm -i fenbi-desktop_*.rpm`

## 用法

打开 app 就直接落在题库目录页，**上次选的考试分类会自动恢复**，不用重新选。

| 情况 | 行为 |
| --- | --- |
| 第一次打开 | 页面加载后确认本地读不到登录凭证，自动弹出登录框，用**手机验证码**登录（想扫码就点登录框右上角的二维码图标） |
| 之后打开 | 通常直接进题库，不再弹登录框 |
| 本地凭证消失（比如你点了「退出登录」） | 自动弹出登录框让你重新登录 |
| 正在做题时凭证消失 | 一样会弹出登录框（练习数据由网站实时上报，不会丢） |
| 网站拒绝了会话，但本地凭证还在 | app 无法察觉，由网站自己提示你重新登录 |

页面顶部是默认展开的 **36px 工具横栏**：左侧四个仅图标按钮依次用于返回、前进、刷新和回题库，
右侧可收起。鼠标悬停或用键盘聚焦按钮时，横栏空白处会显示操作名称和当前平台的快捷键。
收起后横栏为 24px 高，右侧有「展开」把手，点横栏任何地方都能展开；收起状态会记住。
横栏位于独立的应用区域，不修改网站 DOM，也不随网页滚动或刷新。
如果横栏状态读取失败，可点「重试工具栏」；命令被拒绝时，横栏会显示简短提示。

从练习或报告页点「回题库」（或按对应快捷键）后，可用「返回」回到原页；如果已经在目录页，
这个操作不会重复加载。原页的答题状态能否恢复由粉笔网站决定。

| 作用 | macOS | Windows / Linux |
| --- | --- | --- |
| 返回上一页 | `Cmd + [` | `Alt + ←` |
| 前进 | `Cmd + ]` | `Alt + →` |
| 回题库目录页 | `Cmd + ⇧ + [` | `Ctrl + ⇧ + [` |
| 刷新页面 | `Cmd + R` | `Ctrl + R` |
| 展开 / 收起横栏 | `Cmd + ⇧ + B` | `Ctrl + ⇧ + B` |

### 重新登录 / 换个账号

想在 app 里退出登录：点右上角头像 →「退出登录」。之后会重新弹登录框。

如果 app 的登录状态和网站不一致（比如你想彻底重置），可以删掉本地数据目录。

注意这些命令删除的是**整个应用数据目录**，删掉的是包装层自己写的横栏偏好和窗口位置。WebView 的会话与存储在系统 WebView 里，它们是否跟着清除取决于
平台，所以**不能保证**下次打开一定会要求重新登录——想可靠地退出，用上面的方式点「退出登录」。

```bash
# macOS
rm -rf ~/Library/Application\ Support/com.fenbi.wrapper
```

```powershell
# Windows（PowerShell）
Remove-Item -Recurse -Force "$env:APPDATA\com.fenbi.wrapper"
```

```bash
# Linux
rm -rf ~/.local/share/com.fenbi.wrapper
```

## 常见问题

**界面和网页版一样吗？**

基本一样，但去掉了顶部的「首页 / 课程 / 关于粉笔」等 tab 和整个页脚，只留题库相关的内容。

**会不会影响账号安全？**

它就是内置浏览器打开粉笔官网，登录、会话都由粉笔网站和系统 WebView 处理，
这个 app 拿不到也存不下你的账号密码。

需要说明的是：为了判断「现在还要不要弹登录框」，它**会在本地读取粉笔的登录 cookie**
（只读 cookie 的名字，不读值、不发送到任何地方）。凭证本身始终由系统 WebView 保管。

**能加别的考试分类吗？**

目录页会自己恢复你上次选的分类，所以在网页里选一次就行，不需要改 app。

**窗口尺寸能记住吗？**

能。首次启动窗口最大化，之后每次打开都恢复上次关闭时的尺寸、位置和最大化状态。

## 开发

```bash
pnpm install
pnpm dev      # 编译并启动，约 3 秒
pnpm check    # 提交前跑：语法 + 格式 + 静态检查 + 测试
```

`pnpm build` 只把本地工具栏资源复制到 `dist`，不验证应用。

实现细节、架构说明、排查手册、以及踩过的坑，都在 **[CONTRIBUTING.md](CONTRIBUTING.md)**。
